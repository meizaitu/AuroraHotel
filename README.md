# Aurora Hotel Website

## Assignment
Assignment #2 — Advanced CSS (Flexbox & Grid)

## Topic
Hotel Website

## Project Goal
The goal of this project is to create a responsive hotel website that allows visitors to explore rooms, learn about hotel facilities and send a booking request.

## Target Audience
Tourists, business travellers, couples and families looking for comfortable city accommodation.

## Pages
- `index.html` — Home page
- `rooms.html` — Rooms & Suites
- `about.html` — About the Hotel
- `booking.html` — Booking & Contact

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Media Queries

## Flexbox Examples
- Main navigation
- Hero buttons
- Features section
- Call-to-action section
- Form buttons

## CSS Grid Examples
